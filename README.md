# RhombusEarth

**RhombusEarth** is a web application that visualizes recent global earthquakes on a 3D interactive globe using [CesiumJS](https://cesium.com/platform/cesiumjs/). It fetches real-time earthquake data from official APIs and displays all earthquakes from the last 30 days with magnitude greater than 5.

## Features

- **Real-time Earthquake Data:** Uses up-to-date seismic data for accurate visualization.
- **3D Globe Visualization:** Interactive globe powered by CesiumJS.
- **Magnitude Filter:** Displays only earthquakes with magnitude greater than 5 from the past 30 days.
- **Global Coverage:** View earthquake locations and magnitudes worldwide.

## Tech Stack

- **CesiumJS** for 3D globe visualization
- **JavaScript / TypeScript**
- **Earthquake API** (USGS or similar)
